✧ Key Features

🔥 Populer di Kategori Game

Game adalah kategori aplikasi paling populer berdasarkan jumlah aplikasi yang tersedia.

⭐ Rating Dominan 4.0+

Mayoritas aplikasi memiliki rating antara 4.0 hingga 4.5, menunjukkan kualitas yang cukup baik secara umum.

💸 Gratis ≠ Lebih Rendah

Aplikasi berbayar sedikit lebih unggul dalam rating, namun perbedaannya tidak signifikan dibandingkan aplikasi gratis.

📝 Review vs Rating

Jumlah ulasan berbanding lurus dengan rating tinggi — menunjukkan kepercayaan pengguna terhadap kualitas aplikasi.

📥 Tools & Sosial Paling Banyak Diunduh

Kategori Tools dan Social memiliki rata-rata unduhan yang sangat tinggi dibanding kategori lain.

📦 Ukuran ≠ Rating

Ukuran aplikasi tidak memiliki korelasi kuat terhadap rating yang diterima pengguna.

✧ ABOUT ME

I’m Reky, the creator of DataDeck.

With a passion for clean data visualization and impactful design, I built this platform to simplify how users explore app trends. This project combines modern frontend techniques with meaningful data storytelling.

About the app: DataDeck is a visualization dashboard built from real Google Play Store data. It helps users analyze app categories, trends, and performance in an interactive and elegant way — all in your browser.
