✧ ABOUT ME

I’m Reky, the creator of DataDeck.

With a passion for clean data visualization and impactful design, I built this platform to simplify how users explore app trends. This project combines modern frontend techniques with meaningful data storytelling.

About the app: DataDeck is a visualization dashboard built from real Google Play Store data. It helps users analyze app categories, trends, and performance in an interactive and elegant way — all in your browser.
